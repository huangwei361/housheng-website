## 💰 商业模式

### 收入结构（5:3:2 黄金比例）

- **零售型 50%** — 健康食品、保健品、养生器材、功法周边
- **服务型 30%** — 功法私教、运动课、中医理疗、心理咨询
- **会员型 20%** — 个人年卡 1980 / 家庭卡 3980 / 健康管家 9800-19800

### 关键定价

- 9.9 元体验课 / 免费基础体测 — 引流入口
- 单次课 200-500 元 / 10 次卡 1800-4500 元 — 主力产品
- 健康年卡 1980-3980 元 — 锁定长期
- 健康管家 9800-19800 元 — 高客单

### 私域运营

- 公域（抖音/小红书/视频号）→ 9.9 元体验 → 企微 1v1 + 100-200 人健康群 → 转化会员

## 💡 关键决策记录（2026-09-02）

### 业务方向
1. **业务范围扩展**：从最初的 4 项（营养学+功法）扩展为 **6 大板块**，新增运动、中医、心理、检测
2. **网站结构**：4 大入口 + 1 个品牌 VI 页面（不用 6 个独立页面）
3. **课程分类补充**：用户反馈后增加"**有氧运动**"和"**无氧运动**"两个独立分类

### 品牌决策
4. **品牌名**：候选 6 个（厚生/泰生/未生/原/玄和/同养）→ 选中【**厚生 HOUSHENG**】
5. **Logo 概念**：阴阳双叶 + 圆形底 + 中文厚生 + 英文 HOUSHENG

### 商业模式
6. **收入结构**：零售 50% + 服务 30% + 会员 20%（5:3:2 黄金比例）
7. **启动资金**：80-150 万，建议预备 30% 缓冲至 **150-200 万**
8. **单店模型**：M3 开业 → M6 盈亏平衡 → M12 月营收 100 万 → M24 双店

### 合规红线
9. **中医理疗话术**：用"调理/养护/缓解" — **不用**"治疗/治愈/疗效"
10. **保健品宣传**：严格区分"蓝帽子"和普通食品，普通食品不宣称功效
